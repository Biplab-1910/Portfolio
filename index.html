BuyBuzz

Full-Stack E-Commerce Platform

BuyBuzz is a full-stack e-commerce web application designed to provide a complete online shopping experience. Users can browse products, explore categories, view detailed product information, add products to their cart, buy products directly, and manage their orders.

The platform also includes user authentication and an admin dashboard for product management. Administrators can add, edit and delete products through the dashboard. REST APIs handle communication between the frontend and backend while MongoDB manages application data.
